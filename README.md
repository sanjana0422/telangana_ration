Analysis of Telangana Public Distribution System (PDS) ration shops using unsupervised machine learning to group shops with similar behaviour.
Goal: Help the Civil Supplies Department identify Dormant shops, High-Volume shops, and Mega Urban Hubs for better monitoring, stock allocation, and policy planning.
